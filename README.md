## 💡 О проекте

При разработке игр анализ плейтестов и видео стримеров — ключевой источник обратной связи. Однако ручной просмотр десятков часов видео требует колоссального времени: нужно отслеживать мимику, вздохи, моменты замешательства, пропущенные подсказки интерфейса и повторяющиеся смерти.

**Game Playtest Intelligence Hub** решает эту задачу с помощью новой технологии **Agentic Video Understanding**:
1. **Вы вставляете ссылку на YouTube** летсплея или плейтеста.
2. **Gemini агент динамически исследует таймлайн**, сопоставляет происходящее на экране с речью игрока и эмоциями.
3. Вы получаете детальный аудит с **кликабельными таймкодами `[MM:SS]`**, точками фрустрации и приоритетной матрицей улучшений `[P0 / P1 / P2]`.
4. В один клик запускается **Сводный Мета-рекап** по всем плейтестам игры, выявляющий **системные повторяющиеся боли** и формирующий готовый бэклог задач для команды разработки.

## ⚡️ Почему именно Agentic Video Understanding?

Обычные мультимодальные модели нарезают видео с фиксированной частотой кадров (1 FPS) «в лоб», расходуя сотни тысяч и миллионы токенов.

**Agentic Processing (`"processing": "agentic"`)** работает по принципу агента:
* **Динамическая навигация**: модель сначала сканирует транскрипт и структуру ролика, а затем точечно переходит к ключевым сегментам.
* **Адаптивный фокус**: в критичные моменты (бой с боссом, смерть, реакция на туториал) модель запрашивает больше кадров высокого разрешения.
* **Экономия токенов до 88%**: анализ 30-минутного видео обходится всего в несколько центов.
* **Субсекундная точность**: находит точные секунды замешательства и пропущенные элементы HUD.

## 🚀 Основные возможности

* **🎬 3 источника видео**:
  - **YouTube**: автоматический анализ по ссылке без скачивания.
  - **Локальные файлы** (MP4, MOV, MKV, WebM, AVI): загрузка через браузер (до 2 ГБ) или прямое указание пути на диске.
  - **Google Drive**: автоматическое скачивание по расшаренной ссылке и загрузка в Gemini File API.
* **🛠 Конструктор пользовательских скиллов (Skills / Presets)**:
  - Создавайте собственные экспертные навыки для любого контента: киномонтаж (правило 180°, темпоритм), реклама (хуки первых 3 секунд, удержание), лекции, презентации.
  - Хранение скиллов в `skills/*.json`.
  - Импорт скиллов в один клик из JSON-ответов ChatGPT, Claude или Gemini.
  - Подробная документация и мета-промпт для нейросетей в [`SKILL_SPECIFICATION.md`](SKILL_SPECIFICATION.md).
* **📁 Проекты = Папки внутри `reports/`**:
  Каждая игра или тема изолирована в своей папке (например, `reports/Superweird/`).
* **🧠 Сводный Мета-рекап (Кросс-анализ)**:
  Синтезирует отчёты по нескольким видео, находит паттерны, строит тепловую карту затыков (Chokepoints) и бэклог задач.
* **🖥 Два интерфейса**:
  - Удобный веб-интерфейс на **Streamlit** со встроенным видеоплеером (YouTube + локальные файлы).
  - Быстрый **терминальный CLI** с поддержкой интерактивного режима.

## 🛠 Установка и настройка

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/RecapVideo.git
cd RecapVideo
```

### 2. Создание виртуального окружения
Требуется **Python 3.10+** (рекомендуется 3.12):
```bash
python3 -m venv .venv
source .venv/bin/activate  # Для macOS / Linux
# или .venv\Scripts\activate для Windows
```

### 3. Установка зависимостей
```bash
pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Настройка API-ключа Gemini
1. Перейдите в [Google AI Studio](https://aistudio.google.com/) и создайте API-ключ.
2. Скопируйте шаблон окружения:
   ```bash
   cp .env.example .env
   ```
3. Откройте `.env` и вставьте ваш ключ:
   ```env
   GEMINI_API_KEY=AIzaSy...
   ```

> [!NOTE]  
> **Free Tier vs Pay-as-you-go:**  
> Если вы используете бесплатный тариф (Free Tier) Google AI Studio, для стабильной работы выбирайте модель **`gemini-3.5-flash`** (на моделях 3.8 / 3.7 могут возникать ограничения по квотам).  
> Для продакшена рекомендуется включить Pay-as-you-go в AI Studio: благодаря агентской оптимизации стоимость анализа одного видео составляет **1–5 центов**.

## 🖥 Использование через Веб-интерфейс (Streamlit)

Запустите веб-приложение:
```bash
./run.sh
# или напрямую:
streamlit run app.py
```
Откройте браузер по адресу: **http://localhost:8501**

### Доступные разделы:
1. **🧠 Сводный Мета-рекап (Кросс-анализ)**:
   - Выберите нужную игру в боковой панели.
   - Отметьте галочками отчёты для анализа (отображаются каналы и просмотры).
   - Нажмите **«Запустить сводный кросс-анализ»**, чтобы получить единый системный отчёт со сводной таблицей задач для команды.
2. **📹 Анализ видео (Новый рекап)**:
   - Вставьте ссылку на YouTube (видео, shorts, youtu.be).
   - Выберите пресет анализа и при желании введите свои вопросы к плейтесту.
   - Нажмите **«Начать анализ видео»** — отчёт с кликабельными таймкодами сохранится в папку активного проекта.
3. **📁 Отчёты проекта**:
   - Просмотр, поиск и скачивание всех сохранённых отчётов по игре в `.md`.

## ⌨️ Использование через консоль (CLI)

### Интерактивный мастер
```bash
python cli.py -i
```
Скрипт пошагово предложит выбрать проект, режим (новое видео или мета-рекап) и параметры.

### Прямой запуск команд

**Сводный мета-анализ по игре `superweird`:**
```bash
python cli.py --project superweird --meta
```

**Анализ нового видео:**
```bash
python cli.py --project superweird \
  --url "https://youtu.be/VIDEO_ID" \
  --preset full_ux_audit \
  -q "Понял ли игрок механику крафта?" "Сколько раз умер на первом боссе?"
```

## 🔒 Безопасность и деплой

* Файл с секретами `.env` добавлен в [`.gitignore`](.gitignore) и **никогда не попадает в git-коммиты**.
* В репозитории опубликован только безопасный шаблон [`.env.example`](.env.example).
* **Деплой на Streamlit Community Cloud / HuggingFace Spaces / Cloud Run:**
  При деплое добавьте переменную `GEMINI_API_KEY` в раздел **Secrets / Environment Variables** платформы, не передавая файл `.env`.
