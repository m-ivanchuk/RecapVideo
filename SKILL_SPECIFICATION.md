# 🧠 Спецификация и руководство по созданию навыков (Skills / Presets) для RecapVideo

Данный документ описывает структуру **навыков (Skills)** для системы видеоанализа **RecapVideo** на базе **Gemini Agentic Video Understanding**, а также содержит **готовый Мета-промпт для любой нейросети** (ChatGPT, Claude, Gemini, DeepSeek), с помощью которого можно сгенерировать готовый скилл под любую задачу за один запрос.

---

## 🎯 Что такое Скилл (Skill) в RecapVideo?

**Скилл (Skill / Пресет)** — это модуль специализированной экспертизы для мультимодальной нейросети Gemini. Он настраивает модель на решение конкретной аналитической задачи при просмотре видео:
* 🎮 Геймдев: аудит UX, онбординга, боевки, левел-дизайна и затыков.
* 🎬 Кинематограф и видеопродакшн: классический монтаж, правило 180°, темпоритм, чередование планов, саунд-дизайн.
* 📢 Маркетинг и соцсети: анализ удержания внимания, хуки первых 3 секунд, динамика, призывы к действию (CTA).
* 🎓 Образование и лекции: понятность объяснения, визуализация тезисов, удержание студента.
* 🎤 Интервью и подкасты: динамика диалога, баланс гостя и ведущего, язык тела.

Скиллы хранятся в папке `skills/*.json` и автоматически подхватываются веб-интерфейсом и консольной утилитой.

---

## 📋 JSON-схема структуры Скилла

Каждый файл в папке `skills/` представляет собой JSON-объект со следующими обязательными и опциональными полями:

```json
{
  "id": "уникальный_латинский_идентификатор",
  "title": "Эмодзи + Читаемое название навыка",
  "description": "Краткое описание (1-2 предложения) для селектора в интерфейсе.",
  "category": "cinema | gamedev | marketing | education | interview | general",
  "system_role": "Определение экспертной роли и инструкций модели.",
  "rules": [
    "Обязательное правило 1 (например, таймкоды [MM:SS])",
    "Обязательное правило 2"
  ],
  "prompt_focus": "Детализированная структура анализа, разбитая на пронумерованные блоки с вопросами и критериями."
}
```

### Описание полей:

| Поле | Тип | Обязательное | Назначение |
| :--- | :--- | :--- | :--- |
| `id` | `string` | Да | Уникальный ID в нижнем регистре (`a-z0-9_-`), совпадает с именем файла: `skills/{id}.json`. |
| `title` | `string` | Да | Название с эмодзи, отображаемое в выпадающем списке интерфейса. |
| `description` | `string` | Да | Краткое пояснение, на чём сфокусирован этот пресет. |
| `category` | `string` | Нет | Категория для группировки (`gamedev`, `cinema`, `marketing`, `education`, `general`). |
| `system_role` | `string` | Да | Ролевой промпт (Persona). Указывает, кем является модель (ведущий монтажер, геймдизайнер, маркетолог) и напоминает о динамическом исследовании таймлайна (`Agentic Video Understanding`). |
| `rules` | `list[str]` | Да | Критически важные правила: требование формата таймкодов `[MM:SS]`, разделение фактов и критики. |
| `prompt_focus`| `string` | Да | Разделы и критерии, по которым модель должна провести ревизию видео, и структура итогового отчета. |

## ⚡️ Критические правила для Gemini Agentic Video Understanding

При разработке скилла важно учитывать особенности работы агентского видео-анализа:

1. **Формат таймкодов строго `[MM:SS]` или `[HH:MM:SS]`**:
   В приложении RecapVideo работает автоматический парсер, который превращает таймкоды вида `[04:15]` в **кликабельные ссылки на плеер**. Не используйте форматы `04:15` (без скобок) или `на 4-й минуте`.
2. **Аудио-визуальная синергия**:
   Напоминайте модели сопоставлять то, что происходит на видеоряде, с голосом, интонацией, музыкой и звуковыми эффектами.
3. **Разделение наблюдения и вывода**:
   Сначала модель фиксирует объективный факт (`В кадре персонаж совершает...`), затем даёт экспертную оценку (`Это ломает непрерывность действия, потому что...`).
4. **Конкретный итоговый Action Plan**:
   Всегда требуйте в конце таблицу или список конкретных правок с приоритетами `[P0 / P1 / P2]`.

## 🤖 Готовый Мета-Промпт для генерации скилла через любую LLM

Скопируйте текст в рамке ниже и отправьте его в **ChatGPT**, **Claude**, **Gemini** или другую языковую модель, дополнив своей темой:

```text
Ты — ведущий инженер промптов для мультимодальных систем анализа видео (Gemini Agentic Video Understanding).
Твоя задача — создать специализированный навык (Skill / Preset) для инструмента RecapVideo в формате строгого JSON.

Моя тема/задача для анализа видео:
[ОПИШИТЕ ВАШУ ЗАДАЧУ, например: «Анализ видеолекций и образовательных вебинаров» или «Разбор техники выполнения упражнений в фитнесе»]

Сформируй ответ ТОЛЬКО в виде одного блока JSON по следующей схеме:

{
  "id": "латинский_id_в_snake_case",
  "title": "Эмодзи + Название навыка на русском языке",
  "description": "Краткое и емкое описание назначения (1-2 предложения)",
  "category": "одна из категорий: cinema | gamedev | marketing | education | sports | general",
  "system_role": "ТЫ — [ВЕДУЩИЙ ЭКСПЕРТ В ЭТОЙ ОБЛАСТИ]. Твоя цель — провести детальный экспертный аудит прикрепленного видео с помощью агентского анализа видео (Agentic Video Understanding). ДИНАМИЧЕСКИ исследуй ключевые моменты таймлайна, сопоставляй происходящее на экране со звуком и речью.",
  "rules": [
    "ВСЕГДА указывай точные таймкоды в формате [MM:SS] или [HH:MM:SS] для каждого замечания, ошибки или сильного момента.",
    "Разделяй объективные факты (что конкретно видно/слышно) и профессиональную интерпретацию.",
    "Давай только применимые, конструктивные рекомендации."
  ],
  "prompt_focus": "Текст с четко пронумерованными блоками критериев анализа (от 4 до 6 разделов) и финальным разделом с таблицей рекомендаций и таймкодами."
}

Правила:
1. Выводи ТОЛЬКО валидный JSON без вступительного текста и без лишних комментариев.
2. Не экранируй лишний раз кавычки внутри prompt_focus (используй \n для переноса строк).
3. Все таймкоды в правилах и критериях должны быть в формате [MM:SS].
```

## 💡 Примеры готовых скиллов

### Пример 1: Анализ киномонтажа и режиссуры (`skills/cinematic_editing.json`)
* Фокусируется на соблюдении правила 180 градусов, склейках по движению (match on action), джамп-катах, крупностях планов, L-cut / J-cut звуковых переходах и темпоритме сцены.

### Пример 2: Анализ хуков и удержания внимания (`skills/ad_hooks_retention.json`)
* Фокусируется на первых 3 секундах ролика, плотности визуальных стимулов, читаемости без звука, понятности оффера и финальном Call-to-Action (CTA).

## 📥 Как добавить новый скилл в RecapVideo

Есть два простых способа:

1. **Через веб-интерфейс**:
   - Откройте приложение в браузере (`http://localhost:8501`).
   - Перейдите на вкладку **«🛠 Конструктор скиллов (Пресеты)»**.
   - Вставьте сгенерированный JSON в поле импорта и нажмите **«Импортировать скилл»**.
   - Скилл мгновенно появится в списке пресетов на вкладке «📹 Анализ видео»!

2. **Через сохранение файла на диск**:
   - Сохраните сгенерированный JSON в папку `skills/<id>.json` (например, `skills/my_skill.json`).
   - Приложение подхватит его на лету без необходимости перезапуска сервера.
